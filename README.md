## Terminal Emoji Quest

An easy terminal-based game built in Python where you need to navigate into a dungeon, dodge traps, grab a weapon, and defeat demons to advance through floors.

## Prerequisites
* Download the source file or the application from release section
* Run the source file or the application

> ### To run the source file you need to install these librarues
```bash
   pip install blessed yaspin emoji
```

### That's it

## Gameplay

### Controls:
* W to move up
* A to move left
* S to move down
* D to move right
* Q to quite

### Characters:
* 🤠 - It's you
* 🗡️ - Dagger to kill the demon (U need it)
* 👹 - kill it
* 💥 - Trap

> ### That's it, play now.
